OPT_SLAVE_FAILOVER

Used to configure how PhpRedis will fail over to replica nodes when a primary node fails to respond.
FAILOVER_NONE

Never read from replicas.
FAILOVER_ERROR

Attempt to read from replicas when the primary errors out or is down.
FAILOVER_DISTRIBUTE

Distribute read-only commands at random between the primary and replica(s).
FAILOVER_DISTRIBUTE_SLAVES

Distribute read-only commands between the replicas only.
